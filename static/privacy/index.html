개인정보처리방침 (초안)

시행일: (9단계에서 확정)

1. 수집하는 개인정보

만다라트는 이름·연락처·계정 정보 같은 개인정보를 입력받지 않아요. 사용자가 적은 목표와 실천 기록은 기본적으로 사용자 기기의 저장소에만 보관돼요.

1-1. 백업(선택)

설정에서 '백업 켜기'를 누른 경우에만, 토스가 제공하는 익명 식별값을 한 번 더 가공한 키(개인을 알아볼 수 없는 값)와 사용자가 적은 목표·실천 글, 날짜별 체크 기록이 서비스 운영자가 이용하는 Supabase 데이터베이스(대한민국 서울 리전)에 저장돼요. 마지막 백업 후 1년이 지나면 지워지고, 설정의 '백업 끄고 서버 데이터 지우기'로 언제든 즉시 지울 수 있어요. 이 데이터는 백업·복원 외의 목적으로 쓰지 않아요.

2. 광고

서비스에는 앱인토스가 제공하는 광고가 표시돼요. 광고 노출·성과 집계는 앱인토스 광고 정책에 따라 처리돼요.

3. 알림

사용자가 알림 받기에 동의한 경우에만 토스 앱을 통해 하루 1회 실천 체크 알림을 보내요. 알림은 토스 앱 알림 설정에서 언제든 끌 수 있어요.

4. 분석

앱인토스 SDK 의 분석 기능으로 화면 진입·버튼 사용 같은 이용 통계를 기록해요. 개인을 알아볼 수 있는 값은 담지 않아요.
