이용약관 (초안)

시행일: (9단계에서 확정)

1. 서비스

만다라트 플래너(이하 "서비스")는 토스 앱 안에서 제공되는 목표 기록 도구예요. 서비스는 사용자가 적은 목표와 실천 기록을 사용자의 기기에만 저장해요.

2. 이용

서비스는 무료이며 인앱 광고로 운영돼요. 서비스 이용에 별도 가입은 필요 없어요.

3. 데이터

사용자가 적은 내용은 기기에만 저장되고 서비스 운영자에게 전송되지 않아요. 기기를 바꾸거나 토스 앱 데이터를 지우면 내용이 사라질 수 있어요.

4. 책임

서비스는 있는 그대로 제공되며, 사용자가 적은 내용의 보관·복구를 보장하지 않아요.
