# 2차 개발 후보 — AI 초안 (2026-10-19 논의 시작)

> 상태: **채택(2026-10-19)** — 모델 Claude Haiku 5.5, AI 실행마다 리워드 광고 1회. 설계는 `plans/2.0-ai-draft-design.md`(2026-10-20 승인, 5단계 구현 중), API 계약·프롬프트·평가 세트는 같은 폴더. 아래는 처음 논의 기록.

## 한 줄
핵심 목표 한 줄(예: "8구단 드래프트 1순위")을 넣으면 AI 가 세부 목표 8개와 실천 64개 초안을 채운다. 사용자는 고쳐 쓴다.

## 왜 넣을 만한가
- 가장 큰 이탈 지점은 빈 판(73칸을 직접 채워야 함). 지금 대안은 예시 템플릿 2개뿐
- 반복 가능한 리워드 광고 지면이 생긴다(다시 만들기·빈 칸 채우기)
- 비용이 거의 0 에 가깝다(아래)

## 정책 (공식 문서 사본 `ref/official/sections/01-service-open-policy.md` 2-4)
- **사전 고지**: 생성형 AI 기능을 처음 쓰는 시점에 AI 를 쓴다는 사실을 알린다
- **표시**: AI 결과물에 라벨·배지 등 바로 알아볼 수 있는 표시
- 위반 시 과태료 최대 3,000만 원(관련 법령)
- 'AI 채팅·상담' 은 별도 엄격 요건(필터링·자살 안전 프로토콜·모델/프롬프트 변경 시 사전 검토). 이 기능은 대화가 아니라 생성이라 해당하지 않게 **채팅 UI 를 만들지 않는다**. 그래도 위험 목표 거절·자해 키워드 안전 안내는 같은 수준으로 갖춘다
- 처리방침: 입력한 목표 문구가 Anthropic(미국)으로 전송된다는 국외 전송 항목 추가(정적 페이지, 기능 출시와 동시에)

## 비용 (Claude API 가격표 2026-10-19 확인, 1달러 1,400원 가정)
한 번 생성 = 입력 약 2천 토큰 + 출력 약 3천 토큰(한국어 64칸 JSON, 넉넉히)

| 모델 | 입력 / 출력 (100만 토큰당) | 한 판 생성 | 1만 회 |
|---|---|---|---|
| Claude Haiku 5.5 | $0.10 / $0.50 | 약 2.4원 | 약 2.4만원 |
| Claude Sonnet 5.5 | $2 / $10 | 약 48원 | 약 48만원 |

- 기본은 Haiku 5.5(가장 빠름·가장 쌈). 목표 20개로 Sonnet 5.5 와 품질을 비교해 정한다
- 2단계 생성(세부 목표 8개 → 실천 8개씩 8번 병렬)이면 입력이 반복돼도 한 판 약 4원(Haiku). 대신 체감 대기 시간이 짧다
- Supabase Edge Functions 무료 플랜: 월 50만 회 호출, 요청당 실행 150초(대기 I/O 는 CPU 시간에 안 셈)

## 구조
- **서버**: 기존 Supabase 프로젝트에 Edge Function `mandalart-draft` 하나. Anthropic API 키는 Supabase secrets 에만(클라·저장소에 절대 없음)
- **흐름**: 클라 → Edge Function(입력 검사·횟수 제한) → Claude(정해진 JSON 형식) → 서버가 칸 수·글자 수(40자, 권장 16자)·URL·이모지 검사 → 클라
- **2단계 생성**: ① 핵심 목표 → 세부 목표 8개(1~2초, 먼저 화면에 뜸) ② 세부 목표마다 실천 8개를 병렬로 채움. 같은 API 로 "이 세부 목표의 실천만 추천" 도 된다
- **빈 칸만 채우기**: 이미 쓴 글은 그대로 두고 빈 칸만 AI 로 채운다(덮어쓰기 없음)
- **저장**: 서버는 목표 문구를 저장하지 않는다. 기기별 하루 사용 횟수만 센다(익명 키 해시)
- **남용 방지**: 기기별 하루 상한, 전체 하루 상한(넘으면 "잠시 뒤에"), Anthropic 콘솔 월 사용 한도, 입력 40자·출력 토큰 상한
- **실패 시**: 예시 템플릿으로 시작하기를 대신 보여 준다

## 화면 (초안)
1. 빈 판 홈: [AI로 초안 만들기](주) · [예시로 시작하기](보조). 편집 화면에도 [빈 칸 AI로 채우기]
2. 처음 한 번: 고지 시트 "이 기능은 생성형 AI 를 써요. 입력한 목표 문구가 초안을 만드는 데 쓰여요" → 확인
3. 목표 입력(40자) + 예시 칩(8구단 드래프트 1순위 · 토익 900점 · 올해 10kg 감량)
4. 생성 중: 3×3 이 칸마다 채워지는 모습(세부 목표 → 실천)
5. 미리보기(9×9, "AI 초안" 라벨): [이대로 시작하기] · [다시 만들기(광고)] · [닫기]
6. 적용 뒤: 판 제목 옆 "AI 초안" 칩(판 단위 표시), 공유 이미지에 "AI 초안 포함" 한 줄

## 광고
- 기본안: 첫 초안은 무료(첫 경험), 다시 만들기·빈 칸 채우기·세부 목표 추천은 리워드 광고
- 비용이 한 판 수 원이라 광고는 비용 보전이 아니라 수익 지면이다

## 안전
- 위험한 목표(범죄·약물·도박·폭력·선정·혐오)는 생성하지 않고 정해진 거절 문구
- 자해·자살 관련 표현이면 생성하지 않고 자살예방 상담전화 109 안내
- 출력 검사 실패면 한 번 재시도 후 실패 안내
- 검수 대비: 위험 목표 20개 회귀 테스트를 Edge Function 테스트에 둔다

## 계약 변경 예상 (필드 추가만)
- `state` boards[]: `aiDraft { at, model }`(판 단위 AI 표시), settings: `aiNoticeAt`
- `events`: `ai_draft_request` · `ai_draft_apply` · `ai_draft_refused` · `ai_draft_error` · `ai_fill_empty`

## 같이 넣을 만한 것
- **매일 저녁 알림 켜기**: 코드는 있음. 이제 앱이 승인돼 콘솔 MCP 로 기능성 푸시 템플릿을 만들고 승인받으면 `.env` 에 넣고 재빌드. 재방문에 가장 직접적
- **앱 버전 표시**: 설정 화면이 0.1.0 → 이번 빌드부터 package.json 버전을 올린다
- 첫 주 지표(빈 판 이탈, 재방문, 광고 eCPM)를 보고 우선순위를 다시 본다

## 결정 (사용자)
1. AI 초안을 2차에 넣을지 — 기본: 넣는다
2. 광고 방식 — 기본: 첫 초안 무료, 이후 리워드
3. 모델 — 기본: Haiku 5.5, 품질 비교 뒤 확정
4. 알림 켜기를 같은 버전에 넣을지 — 기본: 넣는다
5. (사용자 작업) Anthropic 콘솔 계정·API 키 발급·크레딧 충전·월 사용 한도 설정, 키는 `supabase secrets set` 으로 직접 입력

## 공식 문서 확인 반영 (2026-10-19, `/guide/` 36쪽)
- **남용 방지 단위**: 기기별이 아니라 "토스 사용자 × 이 앱" 으로 셀 수 있다 — 사용자 식별키 인증 코드 교환(클라 `User.createAnonymousKeyAuthCode`, SDK 3.6.0 이상 → 서버가 mTLS 로 교환, 코드 300초·1회용). 지금 SDK 3.2.0 이라 업그레이드 필요, mTLS 인증서 발급 조건과 Supabase Edge Function 의 mTLS 호출 가능 여부는 확인 필요. 안 되면 익명 키 해시(위조 가능) + 전체 상한으로 간다
- **호출 한도(정책 2-5 신설)**: 서버 API 사용자당 분당 20건·미니앱당 분당 3,000건, 클라 SDK 10초당 1,000건. 반복·중복 호출과 실패 직후 무제한 재시도 금지 → 재시도는 1회, 실패는 안내로 끝낸다
- **리워드 용도**: "기능 추가 제공" 에 해당해 다시 만들기·빈 칸 채우기를 리워드로 여는 구조는 맞다. 광고 클릭에 보상 금지
- **CORS**: SDK 3.1.0 이상 번들은 `apps.tossmini.com`·`private-apps.tossmini.com` Origin 만 허용하면 된다
- 생성형 AI 고지·표시(2-4) 조항은 10-12 사본과 같다
