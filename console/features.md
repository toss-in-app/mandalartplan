- 2026-10-17 콘솔 MCP 규칙 확인: 영문은 각 단어가 대문자·숫자로 시작(Daily Checkin 가능, Daily checkin 불가), 한글은 앱 이름과 같을 수 없음, 주소는 `intoss://mandalartplan` 으로 시작하는 전체 딥링크. 주요 기능은 비필수라 없어도 검토 요청은 된다.
