## 바뀐 것
### 1. 안드로이드도 전면·리워드 광고를 다시 켬
- **스위치** `client/.env` `VITE_FULL_SCREEN_ADS`: `ios` → **`on`**. 코드는 그대로라 안드로이드도 3.0.0·iOS 와 같은 흐름이다 — 홈 '기록 보기' 전면(하루 1회, AD 표시 + '기록 보기를 누르면 광고가 한 번 나와요' 안내), 리워드 3곳(AI 초안·빈 칸 채우기 / 공유 '고화질로 저장' / 설정 '두 번째 만다라트 판' — AD 표시·'광고 보고' 문구·'광고를 한 번 보면' 안내), 분석 `ad_interstitial`·`reward_unlock`·`ai_draft_reward`.
- **위험**: 3.0.1 에서 끈 이유(안드로이드 토스앱이 광고 이벤트를 늦게/안 보내, 2026-10-22 실기기 영상에서 라이브 리워드 광고를 50초 다 봤는데 앱은 '못 불러왔다')가 고쳐졌다는 공지는 아직 없다. 2026-10-29 확인: 개발 공지 최신은 4951(10/09), 4529(에러 콜백 미호출)는 완료 공지 없음, 비슷한 보고 5057(10/22)에 10/28 토스 답은 "애드몹 자체 로딩이 오래 걸릴 수 있으니 타임아웃을 더 늘리거나 없애는 것도 고려". 사용자가 확인용 라이브 번들로 실기기 확인 뒤 진행.
- 안 되면 `ios` 로 되돌리거나, 보관해 둔 광고 기다림 수정(`47c019a`, 원격 브랜치 `claude/edit-swap-records-padding`: 누른 뒤 10초 안에 준비된 광고만·버튼 로딩 표시·가려짐/터치로 판정·닫힐 때 몰려온 보상 인정·늦은 보상 120초)을 넣는다. 이번에 넣지 않은 이유: 실기기 확인·심사를 거치지 않은 큰 변경이고(약 650줄, 3.0.1 첫 판은 반려) iOS 흐름까지 바뀐다.
- 콘솔 상세 설명은 그대로('핵심 목표만 적고 생성형 AI(Anthropic Claude)를 통해 …') — 광고 언급이 없어 켜도 틀리지 않는다. 바꾸면 앱 정보 검토가 따로 걸린다.

### 2. Microsoft Clarity(사용 기록 분석) — 사용자 2026-10-29
- **켜는 곳**: 공식 npm `@microsoft/clarity` 1.0.2(MIT, 의존성 없음 — `https://www.clarity.ms/tag/<id>` 스크립트를 넣는 작은 로더). `client/src/lib/clarity.ts` — `App.tsx` 가 저장 상태를 읽은 뒤, 설정 '사용 기록 분석'(`settings.analytics.replay`, 기본 켜짐)이 켜져 있고 출시 빌드(MODE=production)에서 `.env.production` `VITE_CLARITY_PROJECT_ID=z58r4u0qo8` 가 있을 때만 `Clarity.init` + 태그 `app_version`. 개발 서버·vitest·`build:test-ads` 는 녹화 안 함. `identify` 를 쓰지 않아 토스 식별값은 보내지 않는다. 실패해도 앱은 그대로.
- **가림 = 콘솔 '균형 잡힘'**(사용자가 Strict → 균형 잡힘으로 바꿈): 입력칸·숫자·이메일 주소는 가리고, 화면 글(적은 목표·실천 포함)은 녹화에 담긴다. 확인용 번들 `20261029-25` 의 `<body data-clarity-mask="True">`(전체 가림)는 콘솔 설정을 덮어써 '균형 잡힘'이 먹지 않아 뺐다. 사용자 판단 '만다라트 내용이 개인정보는 아니잖아' — 대부분 그렇지만 자유 입력이라 이름·병명 같은 글이 섞일 수 있고 처리방침이 '목표·실천 글은 기기에만'이었어서, 처리방침에 '화면 글이 담길 수 있음'·국외 이전·끄는 방법을 적었다(4-1·4-2).
- **설정 '사용 기록 분석'**(TDS `Switch`, 약관 묶음 맨 위): 끄면 `Clarity.consent(false)` 로 쿠키를 바로 지우고, 다음에 열 때부터 아예 불러오지 않는다(열려 있는 동안 기록을 멈추는 공식 API 는 없음 — 클라이언트 API 는 consent·identify·set·event·upgrade 뿐). 토스트 '사용 기록 분석을 껐어요. 다음에 열 때부터 기록하지 않아요'. 계약 `state.schema.json` `settings.analytics.replay`(선택, 없으면 켜짐).
- **CSS 를 페이지 안으로**: 미니앱 주소는 토스 앱 밖에서 열리지 않아(직접 접속 HTTP 400) 클라리티가 재생할 때 CSS 파일을 다시 받지 못한다 → `vite.config.ts` `inlineCss()` 가 빌드 때 CSS(17KB)를 `index.html` 안 `<style>` 로 넣고 CSS 파일을 뺀다.
- **출시 검사**: `scripts/check-release-bundle.mjs` 가 Clarity ID 가 번들에 있는지, CSS `<link>` 가 남지 않았는지도 본다.
- **개인정보처리방침**(`static/privacy/index.html`, 시행일 2026-10-29): 1절에 '사용 기록 분석이 켜져 있으면 화면 글이 담길 수 있음', 4-1 사용 기록 분석(무엇을·가리는 것·쿠키·끄는 방법), 4-2 국외 이전(Microsoft Corporation, 미국 Azure, HTTPS, 항목: 화면 이동·누름·스크롤 기록과 화면 모습·기기/브라우저 정보·IP 주소·쿠키 식별값, 녹화 30일·일부 최대 9개월, 거부 방법). 클라리티 약관상 사용자에게 알려야 한다.
