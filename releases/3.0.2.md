## 바뀐 것
- **왜**: 안드로이드 토스앱의 광고 이벤트 누락은 2026-10-23 기준 그대로다(개발자 커뮤니티 공지 4304(7/8)·4529(8/6, 에러 콜백 미호출 '수정 예정' 뒤 완료 공지 없음), 10/23 새 보고 5057 — 같은 증상, 답 없음). iOS 는 콜백이 정상이고(토스 공지·커뮤니티 보고 모두 안드로이드만), 우리 콘솔 지표도 10/19~22 노출 iOS 82 vs 안드로이드 32. 전부 끈 채로 두면 노출 없는 리워드 지면이 23일 뒤 '삭제예정'(`rewarded-hd-image` 11/11쯤, 나머지 11/14쯤)이 되는데 공지 54047(전면·리워드 지면 신규 생성 오류, 10/21 "아직 완료되지 않았으며") 동안엔 다시 만들 수 없다.
- **광고 스위치** `VITE_FULL_SCREEN_ADS`(`client/.env`): `off` → **`ios`**. `client/src/ads/config.ts` `fullScreenAdsEnabled()` 가 'on' 이면 모두, 'ios' 면 `Device.os` 가 'ios' 일 때만(부를 때마다 읽음 — 가벼운 상수값, 예외나 다른 값이면 false), 그 밖은 off. 이 함수를 읽는 9곳(전면·리워드 훅, 홈·세부 목표·초안·설정·체험판 문구, AI 안내문)은 그대로라 iOS 는 3.0.0 과 같은 화면, 안드로이드는 3.0.1 과 같은 화면이 된다.
  - iOS: 홈 '기록 보기' 전면(하루 1회, AD 표시 + '기록 보기를 누르면 광고가 한 번 나와요' 안내), 리워드 3곳(AI 초안·빈 칸 채우기 / 공유 '고화질로 저장' / 설정 '두 번째 만다라트 판' — AD 표시·'광고 보고' 문구·'광고를 한 번 보면' 안내). AI 는 광고 1회에 1회, 하루 20회. 분석 `ad_interstitial`·`reward_unlock`·`ai_draft_reward` 다시 보냄.
  - 안드로이드: 전면·리워드 없음, AD 표시·안내 없음, AI 초안·고화질 저장·두 번째 판은 바로(AI 하루 20회). 분석은 3.0.1 과 같이 안 보냄.
  - 배너(기록 위젯 판·대시보드 맨 아래 1개)는 양쪽 다 그대로.
- **넣지 않은 것**: 보관해 둔 광고 기다림 수정(`47c019a`, 브랜치 `claude/edit-swap-records-padding`) — 안드로이드 이벤트 누락·심사 반려 대응이라 iOS 엔 필요 없고 실기기 확인·심사를 거치지 않은 코드라, 안드로이드를 켤 때 넣는다(`plans/next-version.md` 0).
- **브릿지 없는 환경**: AIT Devtools(`vite.config.ts` 의 `aitDevtools.vite`, vitest 에서도 모의 브릿지만 켜짐)가 붙은 개발 서버·테스트에서는 `Device.os` 가 'ios' 를 돌려준다(2026-10-23 vitest 로 확인). 그래서 개발 서버에선 테스트 광고가 켜진 채로 보이고, 패널 Environment > OS 를 android 로 바꾸면 다음 렌더부터 꺼진다(패널 값은 새로고침하면 ios 로 돌아가 캐시를 두지 않았다). Devtools 도 호스트도 없는 보통 브라우저에서는 SDK 가 예외(`window.__appsInTossConstants` 없음)를 던져 '모름' → 광고 없음. 실제 안드로이드 토스앱은 호스트가 'android' 를 주입하므로 꺼진다 — QR 테스트에서 안드로이드에 광고가 없는지 꼭 본다. 참고: `getPlatformOS()` 는 SDK 에서 deprecated(`Device.os` 사용 안내)라 `Device.os` 를 쓴다.
- **앱 버전 표시**: 설정 화면 '앱 버전 3.0.2'.
- **다시 바꿀 때**: 안드로이드가 고쳐지면 `.env` 를 `on` 으로 → `npm run check` → QR 테스트(테스트 광고, 안드로이드 실기기에서 리워드 보상 인정 확인) → 라이브 번들 검토. 코드·광고 그룹 ID·콘솔 지면은 그대로.

## 확인
- 테스트: `client/src/ads/config.test.ts`(on·ios·off, 예외·다른 값, 부를 때마다 읽음 — SDK `Device.os` 를 흉내) + `ads/useRewardedAd.test.ts` ios 케이스(안드로이드 = off, iOS = 불러와서 띄움). 테스트 환경은 그대로 `vite.config` `test.env` on 이라 광고 흐름 검사는 전과 같다.
- `npm run check` 통과(계약 검증·타입·린트·테스트 305개·출시 번들 검사: 테스트 광고 ID 0개, 라이브 광고 그룹 4개·설정 5곳·ait 빌드) — 2026-10-23.
- **Devtools 로 양쪽 확인(2026-10-23, 사용자 '양쪽 확인')**: 개발 서버 `vite dev` + AIT Devtools 패널 Environment > OS. **android** → 설정 '두 번째 만다라트 판' 행이 '판을 하나 더 만들 수 있어요 / 만들기', 홈 AI 안내 '목표를 적으면 AI가 세부 목표와 실천을 채워요'(광고 없음, 3.0.1 과 같음). **ios** → '광고를 보면 판을 하나 더 만들 수 있어요 / 광고 보기', 홈 '목표를 적고 광고를 한 번 보면 …'(3.0.0 과 같음). 패널 값은 새로고침하면 ios 로 돌아가므로 `platformIsIos()` 는 캐시 없이 부를 때마다 `Device.os` 를 읽게 했다(패널에서 바꾸면 다음 렌더부터 반영). 토스앱이 상수를 주입하는 부분은 실기기에서만 보인다 — 아이폰 QR 로 확인, 안드로이드는 출시 뒤 콘솔 광고 리포트(OS 별 전면·리워드 노출 0)로 확인.
- 실기기(QR 테스트 번들, 테스트 광고): **아이폰** — 홈 '기록 보기'에 AD 표시·안내가 보이고 전면 광고가 하루 1회 뜨는지, AI 초안 버튼에 AD 표시·'광고 보고' 문구가 있고 광고를 끝까지 보면 초안이 만들어지는지, 설정 두 번째 판 '광고 보기', 공유 '고화질로 저장' 안내·광고. **안드로이드** — 3.0.1 과 같이 광고·AD 표시 없이 바로 열리는지. QR 번들에서 광고는 테스트 광고 ID 라 눌러도 된다(라이브 번들 QR 은 광고 클릭 금지).
- 콘솔 상세 설명: 라이브 설명은 '핵심 목표만 적고 생성형 AI(Anthropic Claude)를 통해 세부 목표와 실천 초안을 자동으로 만들어 채워요'로 광고 언급이 없다 — iOS 만 광고라 그대로 둔다(안드로이드 사용자에게 맞지 않는 문구를 넣지 않음).
- 검토 포인트: 검토자가 안드로이드로 보면 3.0.1, iOS 로 보면 3.0.0 과 같은 광고 흐름이다. 둘 다 승인받은 모양이고, 광고로 가는 버튼엔 모두 AD 표시와 사전 안내가 있다(3.0.1 첫 번 반려 사유 '예상하기 어려운 시점에 광고 노출' 해당 없음). 플랫폼별로 광고 유무가 다른 것을 막는 앱인토스 규정은 찾지 못했고, 출시 노트에 일시 조치임을 적는다.
