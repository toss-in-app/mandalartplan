## 바뀐 것(버그 수정)
- **배경**: 사용자 2026-10-22 안드로이드 실기기에서 3.0.0 QR 테스트 번들(테스트 광고)로 AI 초안 광고를 끝까지 봤는데 '지금은 광고를 불러올 수 없어요'가 떴다('광고 봐도 인식이 안 돼'). 앱인토스 공지 'Android 광고 로드 관련 이슈 및 개선 사항 안내'(토스앱 5.266.0+ 광고 이벤트 간헐 미전달)·'Android 광고 로드 실패 시 에러 콜백이 호출되지 않는 현상'과 같은 증상이다. 지면 신규 생성 오류 공지(54047)와는 별개.
- **광고 이벤트가 늦거나 안 와도 견딘다**(고화질 저장·두 번째 판·AI 초안 리워드 셋 다):
  - 불러오기를 30초가 아니라 공식 상한 60초까지 기다리고, 실패하면 5초 뒤 한 번 자동으로 다시 불러온다(버튼을 다시 누르면 또 1회).
  - 광고가 화면을 덮어 웹뷰가 가려지면 show 이벤트가 없어도 뜬 것으로 본다. 네이티브가 요청을 받았다(requested)고 하면 8초가 아니라 20초까지 기다린다.
  - 광고가 닫히거나 화면이 다시 보이면 1.5초 동안 늦게 오는 보상(userEarnedReward)을 기다린 뒤 판정한다.
  - 판정 뒤 10초 안에 온 보상은 크레딧으로 남긴다. 토스트 '방금 본 광고가 뒤늦게 인정됐어요. 다시 누르면 광고 없이 이어서 해요'가 뜨고, 다음 누름은 광고 없이 바로 진행된다. 이벤트는 호출마다 따로 오기 때문에(SDK `callEventMethod` 의 subscriptionId) 다음 광고의 보상이 앞 광고의 크레딧으로 잘못 잡히지 않는다.
- **초안 화면 '다시 시도'**: '지금은 광고를 불러올 수 없어요' 창에 '다시 시도'(본문 '…광고가 늦게 오는 때가 있으니 다시 시도해 보세요'). 홈·세부 목표 화면은 버튼이 바로 옆에 있어 토스트 그대로.
- **분석 이벤트**: `ai_draft_reward` 에 `cause`(unavailable 일 때만 — unsupported / load_timeout / load_error / show_timeout / failed_to_show / show_error / busy / unknown). 콘솔 분석에서 안드로이드의 어느 지점이 끊기는지 본다.
- **앱 버전 표시**: 설정 화면 맨 아래 '앱 버전 3.0.1'.

## 확인
- 테스트 299개(39파일)·계약 검증·타입·린트, 출시 번들 검사(테스트 광고 ID 0개, 라이브 광고 그룹 4개·설정 5곳) 통과 — 2026-10-22 10:1x `npm run check`, 커밋 `be6634b`. QR 번들은 같은 커밋을 `build:test-ads` 로.
- 실기기(안드로이드, 사용자): 토스앱을 완전히 종료하고 다시 연 뒤 AI 초안 — 창이 더 이상 뜨지 않는지, 뜬다면 뜨기까지 걸린 시간(바로 = 미지원 버전, 1분쯤 = 불러오기 시간 초과, 광고를 다 본 뒤 = 표시 이벤트 누락), '다시 시도'가 되는지, 뒤늦은 인정 토스트 뒤 다시 누르면 광고 없이 만들어지는지.
